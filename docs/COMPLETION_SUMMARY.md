## 📝 **Quick Start (Updated)**

### **1. Install Dependencies**
```bash
cd backend && npm install
cd ../frontend && npm install
```

### **2. Setup Database**
```bash
cd backend
npm run seed
```

### **3. Start Application**

**Terminal 1 (Backend):**
```bash
cd backend
npm run dev
```

**Terminal 2 (Frontend):**
```bash
cd frontend
npm run dev
```
